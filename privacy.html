Privacy policy: devon-uploader

Last updated: 21 November 2026

devon-uploader is a private tool used only by its owner to upload videos to the owner's own YouTube channels. It uses YouTube API Services. By using it you also agree to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

What data it uses

The tool asks for access to the owner's YouTube account (scopes youtube.upload and youtube) only to upload videos, set thumbnails, add videos to playlists and set publish times. It does not access data of any other user.

Storage

The OAuth access token is stored only on the owner's own computer. No YouTube data is sent to any server other than Google's. Nothing is sold, shared or used for advertising.

Revoking access

Access can be removed at any time at Google security settings. Deleting the local token file also removes the tool's access from that computer.

Contact

Questions: open an issue at github.com/azzabrighten-star/devon-uploader/issues.
